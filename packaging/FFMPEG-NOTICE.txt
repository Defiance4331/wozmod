FFmpeg in this download
=======================

wozmod runs FFmpeg as a separate program to convert voice clips. The copy in
the "ffmpeg" folder inside "_internal" is wozmod's own build of FFmpeg 8.1.3
(the release/8.1 branch at commit 29e619e767, n8.1.3-9), with only the parts
the installer uses. It is one program with libvorbis and libogg (Xiph.Org)
and libsoxr (the SoX Resampler library) linked in.

Source code
-----------
The program is built from these sources, unchanged:

  FFmpeg     https://github.com/FFmpeg/FFmpeg   commit 29e619e767cde9045a75c29bc9a8278ae7b3a98b
  libogg     https://github.com/xiph/ogg        commit 06a5e0262cdc28aa4ae6797627a783b5010440f0
  libvorbis  https://github.com/xiph/vorbis     commit 1b75110b5a2754ba1931d82dd83cb822b266a21d
  libsoxr    https://github.com/chirlu/soxr     commit 945b592b70470e29f917f4de89b4281fbbd540c0
             (libsoxr 0.1.3, mirrored from https://sourceforge.net/p/soxr/code)

The script that builds the program from them, with every option it uses, is
packaging/ffmpeg/build.sh in wozmod's source:

  https://github.com/Defiance4331/wozmod

It builds the same program, or your own changed version of it.

If you cannot get the source from these places, ask the wozmod maintainer for it
and we will send it to you.
