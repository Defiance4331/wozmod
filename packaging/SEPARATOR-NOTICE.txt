The Dream voice separator in this download
==========================================

Musou Orochi Z plays its Dream cutscenes in the game engine; their English
voices exist only inside the movies of Warriors Orochi 2 for PSP, mixed with
music. The installer takes the voices out of the music on your machine with
a vocal separation model. The "dream-voice" folder inside "_internal" holds
what it needs.

The model
---------
"separator.weights", "separator.onnx" and "separator.json" are made from the
Mel-Band RoFormer vocal model by Kimberley Jensen
(https://huggingface.co/KimberleyJSN/melbandroformer, file
MelBandRoformer.ckpt, SHA-256
87201f4d31afb5bc79993230fc49446918425574db48c01c405e44f365c7559e): its weights
stored in 4 bits, and its network written out for ONNX Runtime. The script
that makes them is packaging/separator_model.py in wozmod's source.

The network
-----------
The network's design is Mel-Band RoFormer as written in BS-RoFormer by Phil
Wang (lucidrains, https://github.com/lucidrains/BS-RoFormer), which the
network in "separator.onnx" follows. BS-RoFormer is under the MIT License:
see "BS-ROFORMER-LICENSE.txt" in this folder.

On a graphics card
-----------------
Where the machine has a graphics card that can, the network runs on it, in
wozmod's own programs for it: the "separator-*.spv" files, for any card with
a Vulkan driver (compiled from packaging/separator/vulkan/ in wozmod's source
with Khronos's glslang). They are wozmod's work, under wozmod's licence, and
run through the graphics driver already on the machine. The download holds no
part of a Vulkan SDK.

ONNX Runtime
------------
On the processor, which is also the measure every graphics card is checked
against, the network runs in ONNX Runtime 1.32.0 (Microsoft,
https://onnxruntime.ai), whose library is in the "dream-voice" folder as
published in the "onnxruntime" package on PyPI, unchanged. ONNX Runtime is
under the MIT License: see "ONNXRUNTIME-LICENSE.txt", and
"ONNXRUNTIME-ThirdPartyNotices.txt" for the software it contains.

On Windows the folder also holds the files of the Microsoft Visual C++
runtime that ONNX Runtime needs (msvcp140.dll, msvcp140_1.dll,
vcruntime140.dll and vcruntime140_1.dll), as published in the "msvc-runtime"
package on PyPI, unchanged: see "MSVC-RUNTIME-LICENSE.txt".
